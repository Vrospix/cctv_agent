CCTV Query Agent User Guide

A practical walkthrough for running the interface, testing conversational behavior, enabling the optional local model, and verifying the submission.

1. Requirements

  • Python 3.11 or newer
  • A terminal opened in the extracted submission folder
  • Internet access only when installing Streamlit or optionally downloading Ollama

The command-line version uses only Python's standard library. Streamlit is the only required package for the browser interface.

2. Recommended browser interface

Install the interface dependency and start the application:

pip install -r requirements.txt
streamlit run web_app.py

If the command is not recognized:

python -m streamlit run web_app.py

The browser should open automatically. Enter requests in the chat box. The sidebar shows examples, active filters, a Start over button, and the optional local-AI toggle. Stop the server with Ctrl+C.

3. Command-line usage

Run one request:

python main.py ask "Show me PIE frames between 8 AM and 10 AM yesterday."

Start persistent chat:

python main.py chat

Type quit or exit to leave. Records are generated automatically. Manual generation is optional:

python main.py seed --until YYYY-MM-DD

5. Optional local AI

The application works fully without AI. The local model only normalizes unusual wording and never receives database access or generates SQL.

ollama pull qwen2.5:1.5b
python main.py chat --local-ai

In the browser interface, enable Use local AI fallback in the sidebar. No API key is required. Normal requests are handled deterministically first, so enabling the toggle does not call the model for every message.

Suggested fallback test:

Show ECP frames today
/limit 5
next
return to the prior batch
If AI is unavailable or its output fails validation, the deterministic parser continues safely.

6. Automated tests

python -m unittest discover -s tests -v

The suite covers assignment examples, time reasoning, camera variations, conversational context, pagination, ambiguity, guardrails, prompt injection, database generation, and local-AI validation.

7. Troubleshooting

Streamlit is not recognized

Run python -m streamlit run web_app.py or reinstall with python -m pip install -r requirements.txt.

Local AI could not be reached

Confirm Ollama is running and qwen2.5:1.5b is installed. AI is optional; deterministic requests continue to work.

Local AI interpretation did not pass validation

This is an intentional safety fallback. The deterministic interpretation is retained when model output changes unsupported details.

A future date is rejected

The simulated dataset only contains records through the date on which the application is running.
